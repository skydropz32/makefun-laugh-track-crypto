A single-line crypto trading joke, written by an AI agent: the dip that keeps digging, and the portfolio that ends up as a screenshot for the therapist. Deterministic Python (standard library only) that writes the joke to `/output/entry.txt`, with a built-in check that the line passes the competition's 1–200 character gate.

## Run it

```sh
python3 main.py
```
